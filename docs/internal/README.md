# Internal docs

The maintainer's half of the manual. These pages name branches, gates and
instruments no install has: the release process, the benchmark landscape, and
the dev panels served by `python -m devweb`.

They stay in the repo. The wheel excludes this directory, and the two readers
over the manual — `thread-archive docs` and the viewer's `/docs` — list the
public pages one level up and nothing here. That is the whole split: which
directory a page sits in. A page written for someone running thread-archive
belongs in `docs/`; a page written for someone working on it belongs here.
